## 3. Key Architectural Decisions

1. **System Default Resolution:** Default language resolves to system UI language if `uk` or `ru`, otherwise falls back to English (`en`).
2. **Restart Required for Language Changes:** Catalogs are installed strictly before `MainWindow` and any GUI widgets are constructed in `main.cpp`. Language switching is saved immediately to `ui/language` in `jobprep.ini` / settings, with an inline notice indicating that changes apply on restart.
3. **Data Neutrality:** Stored SQLite database values (status enums, dates) and user data exports (CSV, ICS, JSON) remain completely language-neutral and byte-equivalent across locales. Sample data remains in English.
4. **Locale Independence of Input Formats:** Goal spinbox formatting accepts both comma and period as decimal separators (`7.30` = 7:30, `7,30` = 7:30, `7.5` = 7:50); date editors strictly enforce ISO `yyyy-MM-dd` regardless of system locale.
5. **Option B Accelerators (No Custom Cyrillic Mnemonics):** Custom `&` accelerators are omitted in Ukrainian and Russian catalogs to prevent shortcut collisions and avoid dead shortcuts for users on Latin keyboard layouts. Standard dialog buttons (*OK*, *Cancel*, *Yes*, *No*) continue using Qt's built-in Cyrillic mnemonics via `qtbase_*.qm`.
6. **Native Language Display:** The language selector in Settings displays language names natively: `English`, `Українська`, `Русский`.

## 4. Known Limits & Assumptions

1. **Offscreen Screenshot Rendering:** Captured visual artifacts in `docs/reports/images/i18n/` were rendered in headless offscreen mode using FreeType / DejaVu fonts, which may differ slightly in typography from live desktop rendering on Windows or macOS.
2. **Windows `qtbase_*.qm` Dependency:** Standard Qt button translations on Windows rely on Qt runtime finding `qtbase_uk.qm` / `qtbase_ru.qm` in `%QT_PREFIX_PATH%\translations` or next to the executable.
3. **Accelerator Navigation:** Under Option B, keyboard users navigate custom dialog fields via `Tab` / `Shift+Tab` and trigger default buttons via `Enter` / `Esc`, rather than `Alt+<Cyrillic Letter>`.
