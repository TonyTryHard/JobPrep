- Date popup (Alt+Down and F4 both open it): works everywhere except the **Study page** date control. If the popup is opened by a mouse click on the drop-down button, arrows do not work either. The spin-box part of the same control still changes the date with Up/Down. The other four places behave correctly. Suspected cause (not verified): keyboard focus is not inside the popup's calendar view when the popup opens on that page.

- Weekly goal: `450 min` works, but a Ukrainian/Russian unit does not: `150мин` is read as 150 hours and capped at 40 hours (the unit is ignored).
- Dark theme: the check boxes of the checklist items are almost invisible (the indicator is dark on dark; only the light grey focus highlight makes the control visible). Light theme is fine.
